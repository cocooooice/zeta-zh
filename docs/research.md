# Zeta 产品调研与适配记录

调研日期：2026-10-27。范围为公开页面、公开加载的前端资源，以及官方产品介绍。没有登录账号、创建聊天、购买权益或调用 Zeta 私有 API。

## 产品定位

Zeta 是 Scatter Lab 的互动故事平台，用户以角色和世界设定为起点，通过对话参与剧情，也能创作故事内容。官方称其底层故事模型为 Spotwrite。产品重点是持续参与故事和角色关系。

来源：[Scatter Lab 官方介绍](https://scatterlab.com/)、[Zeta 首页](https://zeta-ai.io/en)。用户规模和使用时长属于官方自报数据，本调研未独立验证，故不作为扩展设计依据。

## 可确认的产品结构

公开首页有首页、排行榜、发现、创作、聊天、个人页入口。故事卡片展示标题、简介、标签与互动量；公开详情页展示故事设定、人物信息、开场白和评论入口。对中文用户来说，内容理解与界面操作都存在语言需求。

官方更新还介绍了剧情中的掷骰事件、角色短信和角色日记，具体可用性依模型、创作者设置和账号逐步开放。这意味着待翻译内容不仅是简单的聊天气泡。

来源：[官方功能公告](https://zeta-ai.io/en/announcements/12277)。

## 语言与技术观察

- 页面 `hreflang` 与公开前端路由配置列出 `ko`、`ja`、`en`，默认 `en`；调研中未看到官方中文路由。
- Web 使用 Next.js／React，存在客户端导航、动态内容及流式 HTML。仅加载时替换一次文字会漏掉后续更新。
- 公开故事开场白可观察到 `StaticIntroMessage`、`BubbleContainer`、`ChatBubbleContainer` 等 `data-sentry-component` 标记，以及 `p` / `em` 结构。
- 公开路由资源中存在 `/[locale]/rooms/[roomId]`，但没有进入登录后的真实会话进行验证。

这些是调研日的实现细节，不能作为永久接口契约。原始抓取只存放在本机临时目录，不随项目发布。

## 实现决策

| 需求 | 实现 | 原因 |
| --- | --- | --- |
| 常见界面中文 | 本地精确词典 | 无网络、无模型费用，翻译可审阅 |
| 长文／聊天中文 | 按需本地 Translator API，或自备 API | 覆盖动态故事内容 |
| 保留上下文 | 原文旁附译文；选区译文在隔离面板显示 | 不改写故事内容和提交数据 |
| 页面动态更新 | 观察 DOM，去抖应用词典 | 适应 React 导航和新界面节点 |
| 聊天隐私和费用 | 手动触发、有段数和字符上限 | 用户明确决定发送范围 |
| 站点改版风险 | 通用选区翻译作为备用 | 减少对哈希 class 和私有接口依赖 |

## 验证边界

公开首页和公开故事页经独立无登录浏览器访问；模拟页面用于行为回归。没有借用用户登录态，也没有替用户发消息。真实登录会话、浏览器本地语言模型下载与翻译、真实付费 API 均需安装后进一步验收。
